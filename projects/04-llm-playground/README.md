# Local Text Generation Playground

Roadmap topic: LLM.

Explore sampling and temperature with a tiny character n-gram model. Run python main.py, or compare python main.py --temperature 0.4 with python main.py --temperature 1.2.

This is a teaching model, not a pretrained LLM: it learns short patterns from a tiny text file and has no neural network. Run python main.py --smoke for a deterministic offline check.
