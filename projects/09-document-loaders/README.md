# Document Intelligence Loaders

Roadmap topic: Document Loaders.

Load TXT, Markdown, CSV, and HTML files with the standard library. Optional handlers add PDF and DOCX support. The load_url function fetches HTML only when called. Install requirements-optional.txt for PDF and DOCX, then run python main.py for local examples.

Only load web addresses you trust. The bundled smoke check uses local files and makes no network requests.
