# Mini Transformer

Roadmap topic: Transformer.

Inspect positional encoding and causal self-attention in a decoder-style forward pass. Use Python 3.10 or newer. Install NumPy with python -m pip install -r requirements.txt, then run python main.py.

The random weights are untrained; numeric values illustrate tensor flow and are not useful generated text. Run python main.py --smoke for the offline shape and causal-mask check.
