# LangChain LCEL Workflow

Roadmap topic: LangChain.

Compose a prompt, a runnable model fixture, and a string output parser with LangChain Expression Language. Install langchain-core from requirements.txt and run python main.py.

The local runnable keeps the example offline and needs no credentials. Replace it with a chat model runnable when connecting a provider. The root check reports a skip if langchain-core is not installed.
