# Hybrid Retrieval and Reranking

Roadmap topic: Advanced RAG.

Expand query terms, combine lexical and hashed-vector rankings with reciprocal rank fusion, rerank, and diversify the final evidence chunks. Run python main.py and compare source names for different questions.

The vector features and reranking are compact teaching heuristics, not production components. Hashed vectors are not neural embeddings. The output includes evidence sources to support citations.
